# 🤖 Rangilo – Automation Testing with Cypress

This repository contains an automation testing project for the e-commerce website [RangiloShop.in](https://rrangiloshop.in/) using **Cypress** and **JavaScript**. It includes test cases for core functionalities like navigation, product pages, cart operations, and UI validations.

---

## 🧪 Purpose

The goal of this project is to perform **end-to-end automated testing** to ensure that the key workflows on the website work as expected and remain stable over time.

---

## 🛠️ Technologies Used

- **JavaScript**
- **Cypress**
- **Node.js**
- **Mocha & Chai** (built-in with Cypress)
